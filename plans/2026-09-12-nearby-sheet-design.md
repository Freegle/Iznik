# Nearby as a sheet over the chat

Decision 2026-09-12: the browse equivalent in chat mode is a bottom sheet over the chat,
not a page and not cards in the transcript. Supersedes the Nearby screen in
`2026-09-08-chat-first-design.md`.

## What the member sees

- The transcript never holds post cards. Nearby, a typed search, and the matches shown
  before an Ask all produce one compact strip under the assistant's line: a count
  ("14 offers within 3 miles"), up to three small thumbnails, and a Look button. The
  landing's "Offered near you recently" is the same strip.
- Nearby in the composer, or Look, raises a sheet over the chat to about 85% of the frame
  with a handle and a close. Inside, top to bottom: search box, All / Offers / Wanted, one
  row per item (48px thumbnail, title, type, distance), nearest first. Rows scroll inside
  the sheet. Show more appends ten more inside the sheet. The chat and the page never grow.
- Tapping a row expands it in place: photo, description, Reply. Reply closes the sheet and
  starts the reply in the chat as today.
- No known location: the sheet opens on the postcode field. Nothing found: the existing
  empty lines.
- `/browse` and `/browse/<term>` in chat mode render the chat with the sheet up and the
  term filled, so existing links keep working. Classic browse is untouched.

## Components (iznik-nuxt3/components/chatshell)

- `ShellSheet.vue`: backdrop, sheet, header with title and close, scrolling body, optional
  footer slot. Lifted out of `ChooserSheet.vue`, which is rebuilt on it.
- `NearbySheet.vue`: search, filter, paging, postcode prompt, expand and reply. Reads
  `assistant.nearby`.
- `PostRow.vue`: the compact row; expanded, it shows the `PostCard` body.
- `PostStrip.vue`: count, thumbnails, Look. Replaces every `PostCard` in `FreegleChat.vue`.
- Removed: `NearbyScreen.vue` and its spec. `pages/browse/[[term]].vue` in chat mode renders
  `FreegleChat` with the sheet open.

## Data flow

- `useHostActions.listNearby` and `search` fetch the lean list nearest first as now and
  store it whole in `assistant.nearby = { term, filter, rows, at }`. `assistant.cards`
  carries only `{ kind: 'posts', ids: top three, count }`.
- The sheet pages through `nearby.rows`, fetching full records ten at a time. Search typed
  in the sheet re-runs the host search without leaving it. Filter is applied to the rows
  already fetched.
- `findMatches` fills the same `nearby` and `cards`, so the Ask matches use the same strip
  and sheet.
- The `nearby` host event carries `count`; the engine records `nearbyCount` in facts so the
  composed line may say the number. The NEARBY and ASK_MATCHES prompts say the host shows
  a count and a way to look through them, not cards.

## Errors

- A failed fetch shows the empty line, never a spinner that stays.
- Reply on an item gone since the list was fetched takes the existing "that one has gone"
  path.
