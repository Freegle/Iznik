### INSERT whose generated id is read back (58)

PostgreSQL: INSERT ... RETURNING id. This is the one category that gets EASIER on Postgres - RETURNING is part of the statement, so the id comes back with the insert and the connection-scoped LAST_INSERT_ID() problem disappears entirely. GORM exposes it via clause.Returning, so these sites may become convertible during the port rather than staying raw.
