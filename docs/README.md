# Freegle documentation

This folder is the home for Freegle's product documentation: how the site and app
actually work, for the people who use them and the people who build and run them.

It is organised by **audience**. Read the section that matches who you are.

| Section | Who it is for | Start here |
|---------|---------------|------------|
| [members/](members/) | Freeglers using the site or app to give and get things | [members/README.md](members/README.md) |
| [moderators/](moderators/) | Volunteers running a community with ModTools | [moderators/README.md](moderators/README.md) |
| [developers/](developers/) | People writing code for the platform | [developers/README.md](developers/README.md) |
| [ops/](ops/) | People deploying, monitoring and keeping the service running | [ops/README.md](ops/README.md) |

## What this documentation is (and is not)

- It explains **how things work** from the point of view of each audience.
- The **member** and **moderator** guides are task-focused how-tos, with screenshots.
- The **developer** guide is a thin orientation layer. The code is the source of
  truth, so these pages tell you where things live and which door to walk through,
  then link into the code and the existing reference docs rather than restating them.
- The **ops** guide describes how Freegle is currently organised operationally, at an
  architecture level only. It contains **no secrets, credentials, IP addresses or
  private hostnames**. See [ops/README.md](ops/README.md) for the rule we hold to.

It is **not** a place for organisational information about Freegle the charity
(governance, finances, people). Keep that elsewhere.

## How these docs stay up to date

Documentation drifts out of date the moment it stops living next to the code. So:

- Docs live **in the repo** and change **in the same pull request** as the code they
  describe. A UI change and its screenshot update are reviewed together.
- Screenshots are **regenerated by Playwright** from the running app, not pasted in by
  hand. See [screenshots/README.md](screenshots/README.md).
- Each page carries `last_reviewed` front matter so staleness is visible.

The full set of conventions is in [maintaining-docs.md](maintaining-docs.md). Read it
before adding or changing a page.

## Terminology

A quick glossary for newcomers to Freegle:

- **Freegle** - a UK network of local online communities for giving and getting unwanted
  things for free, to keep them out of landfill.
- **Freegler** - a member of Freegle.
- **OFFER** - a post giving something away.
- **WANTED** - a post asking for something.
- **TAKEN / RECEIVED** - how a post is closed once the item has changed hands (TAKEN for
  an OFFER, RECEIVED for a WANTED).
- **Community / group** - a local Freegle area a member belongs to. A member can belong
  to several.
- **Rippling out** - the mechanism that shows a post to people nearby first and widens
  the area over time if nobody local takes it. See
  [../RIPPLING-OUT-FOR-MEMBERS.md](../RIPPLING-OUT-FOR-MEMBERS.md).
- **ModTools** - the separate app volunteers use to moderate a community
  (modtools.org).
- **ChitChat** - a community discussion feed, separate from OFFER/WANTED posts.
- **TrashNothing** - a partner platform whose users can post to Freegle communities. See
  [../TRASHNOTHING.md](../TRASHNOTHING.md).
